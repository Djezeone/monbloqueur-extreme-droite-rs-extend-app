# FIL CLAIR — guide débutant V2

FIL CLAIR est un carnet personnel accompagné de guides vers les réglages officiels. Il ne lit pas vos fils et ne change pas leurs algorithmes à votre place. Aucune inscription, compte Google/Apple, connexion sociale, extension ou installation n’est nécessaire au carnet. Les réglages d’un fournisseur peuvent, eux, demander son compte.

## Premier démarrage

1. **Choisir mes services** : cochez seulement les services utiles. Vous pouvez n’en choisir aucun ; Local / autres services reste disponible. Ce choix ne connecte aucun compte.
2. **Choisir les catégories** : comptes/chaînes, médias/sources, sujets, recommandations. Gardez au moins une catégorie ; vous pourrez modifier ce choix.
3. **Enregistrer mes choix** : dans Mes flux, choisissez un service, une catégorie et le contrôle proposé. Lisez sa portée, puis donnez un nom ou une courte note à votre cible. N’inscrivez jamais de secret.

Pour voir davantage d’un sujet sans service externe, choisissez Local / autres services → Sujets → Noter un sujet à voir davantage. Pour garder une liste de médias indésirables, choisissez la catégorie Sources. Une note locale organise vos intentions : elle ne filtre pas vos applications.

## Agir et suivre

| Affichage | Ce qu’il signifie |
| --- | --- |
| Note locale | Mémo enregistré dans cet espace, sans action chez un fournisseur. |
| À faire | Guide choisi ; aucune action distante effectuée ou vérifiée par FIL CLAIR. |
| Déclaré effectué · non vérifié | Vous avez confirmé avoir fait la manipulation vous-même. |
| Confirmation API | Cette version n’en produit aucune ; le compteur reste à zéro. |

L’aide embarquée décrit les gestes et leurs limites. Le lien **Aide officielle** nécessite Internet, ouvre un autre onglet et peut être pris en charge par une application selon votre système. Il ne contient pas votre cible. Consultez le fournisseur dans son application ou son site habituel, puis revenez ; FIL CLAIR ne surveille pas ce retour. Si le menu diffère ou manque, gardez la fiche à faire et consultez l’aide officielle.

Un compte masqué peut rester suivi. Un désabonnement ne bloque pas les recommandations. « Pas intéressé » est un retour au classement, sans garantie d’exclusion. « Ne pas recommander la chaîne » ne bannit pas ses résultats de recherche. Le blocage d’un compte limite les interactions selon sa plateforme ; ce n’est pas une garantie de confidentialité du contenu public.

**Déclarer effectué** demande une confirmation qui rappelle la cible et la portée. Ne confirmez que ce que vous avez fait. **Remettre à faire** retire seulement la déclaration. **Retirer le choix** oublie sa fiche localement : cela ne débloque, ne réabonne et ne réautorise rien chez le fournisseur. Pour un retour arrière distant, suivez le réglage correspondant chez celui-ci.

**Modifier mes choix** permet de changer services et catégories sans supprimer les fiches déjà créées. La recherche du carnet retrouve les cibles, services et types de contrôle. Limite : 500 choix, 200 caractères par cible. Pour corriger le texte ou le contrôle d’une fiche, retirez-la puis ajoutez le choix corrigé.

## Listes de profils

Mes listes conserve le parcours de profils déjà présent. Ajoutez un pseudo ou un lien reconnu, ou importez une liste JSON. Les boutons de blocage/sourdine ne sont proposés que pour les contrôles documentés dans le catalogue. Les anciennes déclarations restent des déclarations historiques. La liste publique X est facultative, éditoriale et à examiner ; son import ne bloque personne et ne prouve aucune affiliation politique.

## Sauvegarder, restaurer et effacer

- Dans Réglages, **Sauvegarder toutes mes données** exporte listes, déclarations, historique et Mes flux dans un fichier JSON lisible. **Exporter la liste active** contient seulement ses comptes et sa provenance, sans Mes flux.
- Retrouvez le fichier téléchargé et gardez-le en lieu sûr : il peut révéler vos préférences. Sur iPhone/iPad, regardez dans Fichiers et les téléchargements configurés. Aucun envoi dans iCloud ou autre cloud n’est automatique.
- **Restaurer une sauvegarde** vérifie le fichier avant de demander de remplacer l’espace courant. Exportez l’état courant au préalable si vous souhaitez le conserver. Une sauvegarde incorrecte est refusée ; elle ne devient pas un espace vide.
- **Effacer toutes mes données** efface le contenu courant de ce navigateur après confirmation, y compris Mes flux. Les fichiers téléchargés et les réglages des fournisseurs restent séparés. En espace temporaire, seule la mémoire courante est effacée.

La confirmation de restauration nomme les listes, Mes flux, déclarations et historique remplacés. Une sauvegarde ancienne sans Mes flux les retire de l’espace courant après votre accord explicite. Un remplacement réussi ou un nouvel espace temporaire vide aussi les brouillons non enregistrés et les recherches/filtres de l’interface ; une annulation ou un refus de stockage les conserve.

En cas de données illisibles, les modifications sont suspendues. Exportez la **source de récupération**, puis restaurez une sauvegarde valide ou effacez explicitement l’état concerné. Cette source brute peut être invalide et contenir des champs inconnus : protégez-la, ne la partagez pas publiquement.

## Safari, autres navigateurs et hors ligne

L’installation est facultative. Sur iPhone/iPad Safari, consultez Partager puis l’ajout à l’écran d’accueil et le mode app web s’il est proposé. Sur Mac Safari, l’ajout au Dock dépend de la version. Android et les autres navigateurs ont leurs propres commandes, parfois seulement un raccourci. Réglages contient les parcours de secours ; un favori et l’usage en onglet suffisent au carnet.

Les données peuvent être séparées entre navigateurs, onglet et app installée. Pour transférer vos choix, exportez puis restaurez le fichier dans le contexte voulu ; aucune synchronisation n’est activée. Changer de domaine ne transfère pas automatiquement le stockage. Utilisez une version V2 pour restaurer Mes flux : une ancienne application peut les ignorer puis les perdre si elle réécrit le fichier.

Après un premier chargement complet, si le navigateur a conservé le cache, le carnet et les étapes embarquées peuvent fonctionner hors ligne. Les sites des fournisseurs, l’aide externe et les nouveaux imports publics exigent Internet. Une première ouverture sans réseau ou un cache effacé n’est pas couverte.

Le navigateur peut refuser ou supprimer les données : mode privé, paramètres restrictifs, manque d’espace, éviction ou effacement manuel. Ne comptez pas sur une conservation en navigation privée. Si les écritures sont refusées ou qu’un autre onglet a modifié l’état, exportez la vue utile puis rechargez. Fermez les anciens onglets après une mise à jour.

**Ouvrir un espace temporaire** est un secours explicite dans Réglages. Il commence vide, garde vos données persistantes intactes et ne les fusionne pas. Sa bannière reste affichée : fermeture, rechargement ou arrêt du navigateur peuvent perdre son contenu. Exportez cet espace avant de partir.
