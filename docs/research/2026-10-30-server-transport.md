# Sources primaires — frontière Mastodon serveur

Vérifiées le30octobre2026, Europe/Paris (lecture commencée29/10à23:53UTC). Lecture documentaire seulement, aucune requête de compte social.

- [Méthodes accounts officielles](https://docs.joinmastodon.org/methods/accounts/) : verify_credentials utilise profile ; relationships utilise read:follows ; block/unblock utilise write:blocks. Succès200 avec compte/relation. Le blocage peut précéder sa répercussion dans les timelines : la lecture de relation et l'effet de recommandation restent distincts. profile et with_suspended imposent la qualification d'une instance4.3+ pour ce périmètre précis.
- [Scopes](https://docs.joinmastodon.org/api/oauth-scopes/) : permissions granulaires préférables ; les trois scopes exacts capturés dans le code ne prouvent pas qu'un serveur les a réellement accordés.
- [Durée des jetons](https://docs.joinmastodon.org/api/oauth-tokens/) et [OAuth/révocation](https://docs.joinmastodon.org/methods/oauth/) : pas d'expiration automatique générale des jetons ; la durée locale du handle n'est pas une révocation fournisseur. La révocation officielle est une opération serveur distincte avec client/secret/token, non implémentée ni exécutée ici.
- [HTTPS Node](https://nodejs.org/api/https.html), [HTTP Node](https://nodejs.org/api/http.html), [DNS](https://nodejs.org/api/dns.html), [TLS](https://nodejs.org/api/tls.html) : API native, DNS personnalisé et vérification de nom/certificat. agent:false ne constitue pas une garantie de livraison exactement une fois. L'application doit détruire la requête au délai et ne pas implémenter de retry.
- Inspection du runtime local Node24.22.1 / Undici7.30.1 : branche421 relançant httpNetworkOrCacheFetch observée dans le source embarqué. SHA256 du module et résultat de l'inspection conservés dans les preuves ; aucun extrait de code nécessaire. Ce constat motive le choix HTTPS natif plutôt qu'une hypothèse de POST sans retry via fetch. Il ne qualifie pas toutes versions futures de Node/Undici.
- [Registre IPv4 IANA](https://www.iana.org/assignments/iana-ipv4-special-registry/) et [IPv6 IANA](https://www.iana.org/assignments/iana-ipv6-special-registry/) : bornes de la politique conservatrice du code. Les préfixes spéciaux peuvent inclure des exceptions globalement joignables ; elles restent refusées ici. Multicast IPv4 est bloqué séparément. DNS public ne prouve ni la sécurité d'un fournisseur ni la politique egress d'un hébergeur.

Les bornes de taille/délai et de durée locale sont des choix FIL CLAIR, pas des limites annoncées par Mastodon. Aucun prix/abonnement ni disponibilité de capacité Vercel n'est déduit de ces sources.
