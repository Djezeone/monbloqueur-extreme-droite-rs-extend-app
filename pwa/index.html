        PARAMÈTRES

        Confidentialité et sécurité

        Le mode prudent est permanent

        Pas de scraping, pas de mots de passe, pas d'exécution en masse, pas de connexion API non autorisée. Cette version ouvre les profils officiels et vous demande de confirmer les actions effectuées.

        La version PWA ne peut ni contrôler X, Instagram ou TikTok dans leurs applications, ni connaître leurs listes de blocage. Pour une automatisation future : OAuth officiel, accord explicite et validation du réseau.

        Mes données

        Listes, préférences de flux, états déclarés et historique restent dans ce navigateur. L’application ne synchronise pas leur contenu et n’intègre pas de mesure d’audience. L’hébergeur peut traiter des métadonnées techniques de visite, comme l’adresse IP. Une sauvegarde est un fichier lisible pouvant révéler vos préférences : gardez-le dans un endroit sûr.

        Lire la notice de confidentialité pour les connexions, les exports et l’effacement.

        La sauvegarde complète inclut Mes flux ; l’export de la liste active contient seulement ses comptes et sa provenance. L’effacement du navigateur, une éviction de stockage, un changement de domaine ou de contexte peuvent faire perdre vos données. Aucune récupération par compte ou sauvegarde iCloud n’est garantie.

        Installer sur mon appareil

        L’installation est facultative. FIL CLAIR reste utilisable dans votre navigateur sans compte Google ou Apple.

        iPhone et iPad · Safari

        Ouvrez le site dans Safari, utilisez Partager puis l’ajout à l’écran d’accueil. Activez le mode app web si proposé. Si la commande manque, consultez les actions de partage ou gardez un favori.

        Sur Mac, Safari peut proposer l’ajout au Dock. Les données d’une app web et celles de l’onglet peuvent être séparées : exportez puis restaurez votre sauvegarde pour transférer vos choix. Aucune installation système n’est validée par les tests d’émulation.

        Guide officiel Apple d’ajout à l’accueil ↗
        Android · Chrome, Samsung Internet et Firefox

        Consultez le menu du navigateur : installation, ajout à l’accueil ou raccourci selon le navigateur et sa version. Si aucune commande n’est disponible, utilisez le site et un favori. Chrome n’est pas nécessaire au carnet local.

        Windows, macOS et Linux

        Utilisez le site dans votre navigateur habituel. Chrome ou Edge peuvent proposer l’installation ; Safari sur Mac propose une app web selon sa version. Firefox Windows dispose aussi de fonctions d’app web sur certaines versions. La commande dépend du système ; aucun changement de navigateur n’est requis.

        Le hors ligne nécessite un premier chargement complet et un cache conservé par le navigateur. Les réglages des fournisseurs, les liens d’aide et le chargement d’une liste publique nécessitent Internet. Cette version est en recette ; les marques, appareils et installations physiques non testés ne sont pas certifiés.

        Si le stockage n’est pas disponible

        En navigation privée ou avec des restrictions, le navigateur peut refuser ou supprimer le stockage. Sans verrou de stockage, les écritures sont suspendues pour préserver vos onglets. Lecture et export restent disponibles si les données sont accessibles.

        Vous pouvez ouvrir un espace temporaire vide, indépendant de vos données déjà enregistrées. Il restera seulement en mémoire jusqu’à la fermeture ou au rechargement : sauvegardez-le avant de partir.
